GigaCrowd Support

Having trouble with GigaCrowd, or have a question or feature request? Reach out any time at colin.damage@gmail.com — this is an early build actively being improved, and real reports genuinely shape what gets fixed next.

Common issues

The "Join the Roar" button does nothing / mic access is denied
Check that GigaCrowd has microphone permission: on iPhone, go to Settings → Privacy & Security → Microphone, and make sure GigaCrowd is enabled. If you denied it once, you may need to toggle it on there rather than tapping the button again.
Scanning the QR code opens a browser instead of the app
This can happen if the app was just installed or reinstalled — try closing and reopening the GigaCrowd app once, then scan again. The web version that opens works identically either way, so you can still join the show from there.
"Show not found" when entering a code
Show codes are temporary and tied to the performer's current stream — they stop working once the performer's overlay disconnects. Double check the code with your host, since a stale code from an earlier show won't work.
I'm a performer and my crowd energy isn't updating
Make sure your overlay's Browser Source URL is exactly the one GigaCrowd gave you, and that your Browser Source hasn't lost its network connection. Reloading the source will generate a fresh show code if the old one was lost.
